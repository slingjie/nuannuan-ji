# 暖暖记 · 儿童发烧照护记录

一款无后端、离线优先的手机 PWA。支持多个宝宝档案、体温与实际用药记录、时间线与趋势、JSON 备份恢复和 CSV 导出。记录一次后，下次会自动带入当前宝宝的上次输入；可在保存时勾选「固定这次的…」设为常用模板，再次取消勾选并保存即可解除固定。仅复用输入内容，不自动生成记录；时间默认当前，测温及用药均需重新核对。不同宝宝的固定值相互独立。界面使用原创卡通兔形象，所有数据仅存于当前设备浏览器 localStorage。

## 运行 / 安装

将此目录整体发布到 **HTTPS** 静态站点（如 GitHub Pages、Netlify、Cloudflare Pages），或在电脑上本地运行 `python3 -m http.server 8765` 后访问 `http://localhost:8765/`。首次在线打开后，Service Worker 会缓存应用文件，后续可以离线打开。直接打开 `index.html` 可预览功能，但不能保证安装或离线缓存。

iPhone：使用 Safari 打开已发布的 HTTPS 网址 → 分享 →「添加到主屏幕」。Android：Chrome 打开网址 → 菜单 →「安装应用」或「添加到主屏幕」。PWA 的离线安装能力需要 HTTPS（localhost 例外）。

## 注意

- 本工具仅用于记录，**不提供诊断、推荐剂量、用药间隔或提醒**。请遵循医生建议或药品说明。
- 没有云端同步。更换手机、清除浏览器网站数据或卸载应用前，务必到「设置与数据」导出 JSON 备份，并妥善保管含健康信息的文件。
- 导入备份会覆盖当前数据，操作前需再次确认。
- 若修改静态文件，请更新 `sw.js` 中的 CACHE 版本号，以便安装的客户端获取新版。

项目文件：`index.html`、`style.css`、`app.js`、`sw.js`、`manifest.webmanifest`、`assets/`。
